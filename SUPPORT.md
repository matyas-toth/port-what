# Support

Use [GitHub Discussions](../../discussions) for usage questions and [GitHub Issues](../../issues) for reproducible bugs and focused feature requests.

Before posting, run `port-what --version` and include that version along with your operating system, architecture, Node.js version, exact command, and complete output. Remove usernames, paths, and command arguments that may contain sensitive information.

Security reports must follow [SECURITY.md](SECURITY.md) and must not be posted publicly.
